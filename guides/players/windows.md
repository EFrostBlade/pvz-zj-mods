# Windows 安装 Mod

[返回玩家指南](README.md) · [更新与移除](managing.md) · [遇到问题](faq.md)

适用版本：**0.29.0 / Windows**。源码核对，未重新实机验证；[版本依据](../../MAINTAINING.md)。

## 安装与启用

1. 从作者发布页下载 `.pmod`，查看适用游戏版本及前置依赖。若作者提供的是包含安装包的压缩文件，先取出其中的 `.pmod`；保留 `.pmod` 本身的完整文件。
2. 在游戏主菜单打开 **选项 → Mod 管理**，点击 **导入 Mod**。
3. 在系统文件选择器中选择下载的 `.pmod`。
4. 核对确认框中的名称、作者、版本和 ID，再确认安装。出现同 ID 的旧版与新版信息时，这是替换已有安装包，先确认是自己想安装的版本。
5. 安装完成后确认启用；也可以稍后在列表中选择该作品，点击 **启用**。
6. 正常退出并重新启动游戏，再进入 Mod 管理，确认作品实际已加载。

有前置依赖时，先导入并启用相应依赖；启用失败则查看 **更多 → 查看诊断**，按提示处理。

## 找到作品内容

含关卡目录的作品，可以在 Mod 管理中点击 **游玩 Mod 关卡**。角色、卡牌、外观和工具类作品的使用入口以作者说明为准。

若管理页提示“已启用”但“未加载”，先按要求重启，再检查诊断；单有启用设置不能证明作品已生效。

## 界面与说明不同

旧版教程可能要求手动把文件复制进安装目录。本文使用 0.29.0 的玩家导入入口。若你的界面没有“导入 Mod”，先核对实际游戏版本，并在目录反馈中说明版本和看到的界面。
