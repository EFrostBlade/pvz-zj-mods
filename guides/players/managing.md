# 更新、停用与移除 Mod

[返回玩家指南](README.md) · [兼容说明](compatibility.md) · [常见问题](faq.md)

适用版本：**0.29.0 / Windows、Android**。源码核对，未重新实机验证；[版本依据](../../MAINTAINING.md)。

修改 Mod 状态前先正常结束当前关卡并退出联机房间。若操作仍被阻止，查看诊断，处理依赖或运行状态后再尝试。

## 更新安装包

1. 阅读作者的更新说明，核对新包适用的游戏版本、平台和依赖。
2. 在 **选项 → Mod 管理 → 导入 Mod** 选择新 `.pmod`。
3. 确认框会在同 ID 替换时显示旧版与新版本。核对后确认；不要只根据版本文字判断是否更新，作者可能使用不同的命名规则。
4. 安装后重新确认启用状态，按提示重启游戏。
5. 对照管理页的安装版本与实际运行状态，再进入作品验证自己的使用路径。

如果新包显示为另一个 ID，它可能是独立作品或作者迁移了身份；先查看作者说明，不要直接当作原作品的正常更新。

## 停用

选择作品并点击 **停用**，成功后按提示重启。若其他已启用作品依赖它，先停用那些依赖作品，再处理前置。

“已停用设置”与“本次运行已经卸载”可能不同；以重启后的实际状态为准。

## 删除安装包

选择作品，打开 **更多 → 删除安装包**，阅读确认框后确认。

删除只处理安装包，**保留 Mod 玩家进度**。若界面显示“待删除，重启后移除”，先重启完成删除。待删除期间不能直接用另一个同 ID 包覆盖；完成删除后再重新导入。

若删除被拒绝，先查看依赖、当前运行状态及诊断。不要靠手工改启用文件或删除应用数据绕过提示。

## 进度损坏与恢复

当游戏提示某个 Mod 的进度需要处理时，在管理页选中该 Mod，打开 **更多**：

- **从备份恢复进度**：存在可用备份时，可以恢复当前账号在此 Mod 中的进度配置。
- **重置 Mod 进度**：阅读确认后，将当前账号在此 Mod 中的通关、解锁和收藏重置；这会改变已有进度，不是日常安装步骤。

界面会先保护现有文件。上述操作不删除中途战斗存档，也不重置其他 Mod 或原版进度。确认前核对当前账号和所选作品；若恢复选项不可用，先查看诊断和作者建议。
