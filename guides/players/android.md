# Android 安装 Mod

[返回玩家指南](README.md) · [更新与移除](managing.md) · [遇到问题](faq.md)

适用版本：**0.29.0 / Android**。源码核对，未重新实机验证；[版本依据](../../MAINTAINING.md)。

## 安装与启用

1. 从作者发布页下载支持 Android 的 `.pmod`，记住保存位置。如果下载的是包含安装包的压缩文件，先取出 `.pmod`，不要解开 `.pmod` 本身。
2. 打开游戏主菜单的 **选项 → Mod 管理 → 导入 Mod**。
3. 在 Android 系统文件选择器中找到安装包并选中。云盘中的文件可能需要先下载到设备。
4. 核对名称、作者、版本和 ID，确认安装。同 ID 已有安装包时，先核对旧版与新版信息。
5. 安装完成后确认启用，或者回到列表选择作品并点击 **启用**。
6. 正常结束游戏后重新打开，进入 Mod 管理检查实际加载状态。

Android 的游戏内启停和替换操作需要重启后生效。仅切到桌面再切回仍可能是同一次运行，管理页若继续显示待重启，应确认游戏已结束并重新启动。

## 游玩与平台差异

含关卡目录的作品通过 **游玩 Mod 关卡** 进入，其他内容按作者说明使用。

Android 使用游戏内导入功能管理安装位置，不需要手动查找应用私有目录。手机提供安装、管理与游玩；制作 Mod 使用电脑端编辑器。

即使同一个包在电脑上正常运行，也应核对作者的 Android 支持说明。若提示程序集、依赖或加载失败，查看 **更多 → 查看诊断** 并把信息反馈给作者。
