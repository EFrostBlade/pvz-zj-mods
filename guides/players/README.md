## 下载前看什么

- **游戏版本与平台**：Mod 版本和游戏版本不是同一个编号；Windows 能运行不代表 Android 也能运行。
- **前置依赖**：先取得所需的 Mod 及指定版本。
- **内容入口**：有些作品增加关卡，有些修改角色或外观；并非每个作品都有单独的关卡目录。
- **信息依据**：“未确认”表示缺少资料，不表示兼容或不兼容。

玩家安装的是 `.pmod` 文件。`.pvzmodeproject` 是作者工程入口，源码 ZIP 是创作材料；需要使用作品时，选择作者发布的运行安装包。

0.29.0 在 Windows 和 Android 上都支持 **选项 → Mod 管理 → 导入 Mod**。安装完成、设置启用和当前实际加载是三个不同状态。按提示重启后，再确认管理页中的实际加载结果。
