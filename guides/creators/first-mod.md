# 制作第一个 Mod

[返回创作者指南](README.md) · [发布检查](publishing.md)

适用版本：**0.29.0 / Windows 制作，纯资源入门**。源码核对，未重新实机验证；[版本依据](../../MAINTAINING.md)。下面以新增一个使用内置资源的小关卡为例。

## 1. 创建工程

1. 打开 **选项 → Mod 管理 → 制作 Mod（F3）**，也可以使用电脑端 F3 快捷键。
2. 在编辑器中选择 **文件 → 新建 Mod**。
3. 填写工程名称、Mod 版本、作者和描述，选择保存父目录并创建。Mod 版本可以从 `1.0.0` 开始；它与游戏的 `0.29.0` 分别记录。

编辑器会建立工程目录并打开工程。以后可通过 **文件 → 打开 Mod** 选择 `.pvzmodeproject` 继续编辑。

## 2. 创建可玩关卡

在工程文件树中定位并选中 `Resources/Levels`，使用该目录的新建操作 **创建可玩关卡（含选择目录）**，为关卡填写一个未使用的名称。

这个入口会同时生成关卡资源和配套的关卡选择目录，并绑定普通难度。默认内容使用内置前院地图、普通选卡库和一波普通僵尸，还带有内置章节封面与背景，适合作为入门起点。

创建后确认关卡位于 `Resources/Levels`，配套目录位于 `Resources/LevelCatalogs`。同名关卡或目录已存在时，换一个名称重新创建。

## 3. 完成最小修改

打开生成的关卡资源，在属性编辑中修改显示名称或描述，例如把描述写成这次练习的目标，然后保存。首次操作先保留默认地图、选卡库和波次。

配套目录已经引用这个关卡。显示名称与内部标识用途不同：首次练习保留生成的关卡内部名称、目录 SaveKey 和普通难度绑定，避免改名后引用不一致。

## 4. 导出安装包

选择 **文件 → 保存全部**，再选择 **文件 → 导出 Mod**，指定输出目录。

导出会保存文档并检查资源、目录及相关引用；含脚本时还会编译。只有出现导出成功结果后，才使用对应 `.pmod` 继续安装。遇到错误，先处理编辑器报告；看到旧文件还在输出目录中，不代表本次导出成功。

以下问题可能阻止导出：目录缺少普通难度绑定、SaveKey 重复、关卡内部名称与引用不一致、资源路径不存在。含脚本或声明依赖才能确定的部分可能给出警告，需要后续实际开局核验。

## 5. 按玩家流程验证

1. 按 [Windows 安装指南](../players/windows.md) 导入刚导出的 `.pmod`，启用并重启。
2. 在管理页确认实际已加载，点击 **游玩 Mod 关卡**。
3. 检查章节和关卡是否显示，进入普通难度，确认修改后的内容、选卡和波次表现。
4. 完成关卡并返回，重新启动后检查对应进度，再尝试停用作品并重启。

把实际通过的步骤与未验证项记下来。目录出现、导出成功和完整游玩是不同的检查结果；发布前继续完成 [发布检查](publishing.md#发布前自检)。
