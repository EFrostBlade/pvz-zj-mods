首次创作建议先用内置资源完成一个小关卡，走通创建、导出、安装和游玩，再逐步增加角色、蓝图或脚本。

纯资源工程不需要 .NET 工具链；包含 C# 的工程需要可用的编译工具链。编译失败时先阅读编辑器输出，根据缺失项处理，再尝试导出。

源工程和玩家安装包是两种交付物：保存好可编辑的 `.pvzmodeproject` 及整个工程目录，给玩家发布导出的 `.pmod`。如需分享源码，另行说明源码的打开方式和授权。
