# 植物大战僵尸杂交版 Mod 社区目录

寻找想玩的 Mod，学习安装与制作，把自己的作品分享给其他玩家。

| 想做什么 | 从这里开始 |
| --- | --- |
| 找到新内容 | [浏览 Mod 目录](catalog.md) |
| 安装和管理 Mod | [玩家指南](guides/players/README.md) |
| 制作第一个作品 | [创作者指南](guides/creators/README.md) |
| 投稿、更新或推荐作品 | [参与收录](CONTRIBUTING.md) |

## 第一次使用

1. 在目录中选择作品，查看作者声明的游戏版本、平台和前置依赖。
2. 通过作品详情页前往作者发布页，下载 `.pmod` 安装包。
3. 根据 [Windows](guides/players/windows.md) 或 [Android](guides/players/android.md) 指南，在游戏的“选项 → Mod 管理”中导入、启用并重启。
4. 确认实际加载状态；含关卡目录的作品可以从“游玩 Mod 关卡”进入。

## 关于这个目录

欢迎作者提交作品，也欢迎玩家推荐有可核对来源的作品。已收录内容见 [Mod 目录](catalog.md)。

本仓库维护介绍、指南和原始发布入口，安装包由作者提供。开源与闭源作品均可收录；作品授权以作者说明为准。

“收录”表示资料已核对。兼容说明会标明作者声明、社区实测或未确认；实测记录只对应记录中的版本与平台。

指南面向 **0.29.0**，本轮已核对该版本源码和已有说明，尚未重新实机验证。版本依据与维护检查见 [维护说明](MAINTAINING.md)。

## 反馈

- 目录资料、链接或指南有误：到本仓库 **Issues → New issue → 目录与指南反馈**。
- Mod 本身有问题：优先使用作品详情页中的作者反馈入口，并附游戏版本、Mod 版本及诊断信息。
- 想更新或撤下作品：使用 **更新或撤下条目** 表单，也可以提交 PR。
