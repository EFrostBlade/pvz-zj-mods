## 内容介绍

以下功能依据[作者介绍](https://github.com/apples1949/pvzhe-HealthCooldownLine)整理，未由目录维护者实测：

- 显示加农炮装填、土豆雷出土、大嘴花咀嚼和角色长大的倒计时。
- 显示命名计时器、坑洞消失、周期区域事件触发和磁力消化的倒计时。
- 显示篮球剩余投抛数和投石车剩弹；篮球计数限定有真实弹药的角色。
- 显示阳光、金币、卡包产出与蓄能咖啡豆充能的倒计时。
- 支持多行信息与每行独立颜色，同格叠种的多个角色显示行自动错开。

[观看作者演示](https://www.bilibili.com/video/BV1tyhR6SEkG)。

## 安装与使用

1. 从作者发布页下载 `.pmod`，按照 [Windows](../../guides/players/windows.md) 或 [Android](../../guides/players/android.md) 指南导入、启用并重启。
2. 进入战斗，在战斗设置页找到 **显示冷却倒计时** 开关；作者说明其位于血条开关右列顶部。
3. 启用显示后观察角色血条上方的信息。遇到适配或显示问题时，结合作者说明检查；作者提到日志中可查看候选角色缺组件的诊断。

安装与开关位置依据通用指南及作者介绍，维护者未验证该包的实际运行效果。不要将“工具与前置”分类理解为它必须作为其他作品的前置安装。
